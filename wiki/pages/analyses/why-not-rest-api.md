# Почему не Figma REST API

Естественная первая идея — «extension шлёт данные в Figma по HTTP» — невозможна.

**Figma REST API не умеет создавать содержимое файла.** Он читает файлы и узлы, пишет только комментарии и переменные. Создать фрейм, текстовый слой или компонент через REST нельзя ни при каких правах доступа.

Единственный способ породить содержимое — **Plugin API**, исполняющийся внутри работающего Figma.

## Следствия для архитектуры

1. Система обязательно состоит из двух исполняемых артефактов: extension в браузере и плагин в Figma. Одной половиной обойтись нельзя.
2. Между ними нужен транспорт. Выбран файл — обоснование в [[architecture]].
3. Автоматическая end-to-end проверка результата в самой Figma невозможна: headless-рантайма у Figma не существует. Поэтому проверка фидельности перенесена на уровень IR через референс-рендерер — см. [[correctness-strategy]].

Третий пункт — не мелочь. Он определил всю стратегию тестирования проекта.
